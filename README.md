# Astrabela

Каталог салонов красоты и барбершопов с онлайн-записью и честными отзывами, плюс меню ресторанов. Старт: Лиссабон, затем Португалия и ЕС.

- На сайте есть только салоны, у которых есть кабинет и открыта онлайн-запись.
- Отзыв может оставить только клиент, чей визит салон отметил как состоявшийся.
- Оплату от клиентов платформа не принимает: клиент платит салону на месте.
- Салон платит подписку: 12,99 € в месяц, 10,99 € в месяц за 6 месяцев, 9,99 € в месяц за год. Первые 3 месяца бесплатно.
- Рестораны публикуют меню с ценами и QR-кодом на стол бесплатно.

Концепция и исследование рынка лежат в файлах проекта (`research/beauty-advisor-concept.md`, рабочее название было Beauty Advisor).

## Стек

Next.js 16 (App Router), TypeScript, PostgreSQL, Drizzle ORM, next-intl (PT, EN), Tailwind CSS, Vitest.

## Запуск локально

```bash
cp .env.example .env          # укажите DATABASE_URL
npm install
npm run db:migrate            # создать таблицы
npm run db:seed               # три демо-салона в Лиссабоне
npm run dev                   # http://localhost:3000
```

Демо-вход в кабинет салона: `demo1@astrabela.local` / `demo12345`.

Модератор платформы (одобряет салоны и разбирает жалобы на отзывы): `npm run make-admin -- email@example.com`, затем вкладка «Moderação» в кабинете.

Напоминания клиентам и просьбы об отзыве отправляет `npm run jobs`. Его нужно запускать по расписанию (cron) раз в 5–10 минут. Пока письма выводятся в консоль, подключение почтового сервиса впереди.

## Проверки

```bash
npm run typecheck
npm run lint
npm test   # нужна база astrabela_test (или TEST_DATABASE_URL)
```

## Структура

- `src/db/schema.ts`: таблицы (салоны, мастера, услуги, график, записи, клиенты, отзывы, подписки).
- `src/lib/availability.ts`: расчёт свободного времени мастера.
- `src/server/booking.ts`: запись, защита от двойной записи, отмена, статусы визита.
- `src/server/reviews.ts`: отзывы только после визита, рейтинги салона и мастера, жалобы.
- `src/server/catalog.ts`: поиск салонов и правила попадания в каталог.
- `src/server/notify.ts`: письма клиентам (подтверждение, напоминание, просьба об отзыве).
- `src/app/[locale]/...`: страницы сайта и кабинета салона.
